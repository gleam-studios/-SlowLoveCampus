# 最长30秒分镜规则

## 镜头结构与时间
每镜按顺序包含 `镜头序号｜起止时间`、`视频内容`、`拍摄手法`、`光影执行`、`声音`、`台词`、`结束落点`。镜头使用连续整数秒，首镜0秒，前镜终点等于下镜起点；1—9镜，总时长≤30秒。
`视频内容：` 下按 `[起始秒]—[结束秒]秒：连续画面描述` 写一个或多个时间段。依据动作和视觉变化自由分段，可使用小数，沿用全片绝对时间，覆盖该镜头完整时长。时间分段对应同一镜头的连续推进，镜头切换由下一镜标题表示。
按事件发生顺序写主体动作、人物反应、空间互动、效果与画面变化，呈现动作如何开始、怎样衔接、最后停在哪里。静态展示同样写清这一时间段保持的可见状态。摄影、光影或声音发生特定变化时，将时点融入连续文字，其余字段补充执行要求。

## 背景画面与素材引用
视频内容以自然语言描述本镜可见环境、空间方向及动态，如建筑局部、道路透视、雨水、玻璃反射与远处车灯。场景文件的 `@` 绑定只位于素材锁定的场景分组。人物与道具需要视觉身份控制时沿用原始 `@文件名.格式`，明确持有人、位置与移动方向，跨镜继承状态。

## 台词在时间线中的位置
把每句台词放到视频内容里实际说话的时间段，与当时动作和反应连写，例如：

```txt
12—14秒：站台灯光映在湿润路面上，@人物B.png 看着 @人物A.png，轻轻摇头。@人物B.png说（@人物B音色.mp3）：“我送你到这里就好。”他说话时展开手中的 @红色雨伞.png。
14—16秒：男子将伞柄递向女子，女子握稳后，他松开手，雨伞随女子抬手移到她头顶。
```
每句统一为 `@人物图.png说（@人物音色.mp3）：“台词内容”`，保留中文双引号。未提供音色文件时写 `@人物图.png说：“台词内容”`；未提供人物图时用素材锁定中的角色名称。实际文件逐字引用，音色归属对应角色。

## 台词栏与声音
每镜另有一个 `台词：` 字段。有对白时按发生顺序逐行复写视频内容中的完整台词：

```txt
台词：
@人物B.png说（@人物B音色.mp3）：“我送你到这里就好。”
```
两处的说话者、音色、语句、引号、顺序及次数逐一一致。台词栏作为同一说话事件的索引；口型、表情和听者反应服从正文时间线。无人说话写 `台词：无`。`声音：` 负责环境声和动作音，背景音乐默认无。对白及其伴随动作应在相应时间段内自然完成。

## 摄影、环境与状态
`拍摄手法` 写机位相对主体的位置、景别和实际镜头运动。光影执行与可见空间对应，连续镜头的主光方向稳定，动态变化有明确来源。多镜人物方向、道具持有人和场景拓扑连续；managed 按已批准的镜头数、时间和对白映射。`结束落点` 概括本镜时间线已经达到的画面与状态。
