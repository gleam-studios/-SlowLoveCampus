# 平台约束检查

执行时从真实接入端核实支持模式、参考图片/视频/音频数量与类型、每类大小/时长限制、可选比例、最高片段时长、实际输出分辨率、审核与版权限制、视频扩展/编辑支持情况。只将已核实参数写入执行清单。

本 Skill 的创作合同是**最长30秒的分镜描述**，不等于所有视频生成服务均可单次生成30秒。若目标服务单段最大15秒，先把时间规划交给上游做分段决策；managed 必须重新审批各段，不能直接更换镜头计划。

可见提示词统一使用真实 `@文件名.格式`。平台若使用数字或其他附件标识，执行层必须根据实际上传文件逐项映射并记录对应关系；不可凭视觉描述猜测附件顺序。生成模式与实际附件符合才能执行。

默认无BGM；如果有配音与音效，分镜要有声音事件的触发时间。画幅只作为项目参数交付执行层；不污染四部分可见正文。
