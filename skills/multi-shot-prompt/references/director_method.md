# 独立导演决策方法（仅 standalone）

1. 把 brief 转成观看目的：观众应看到什么、何时理解、最终记住什么。
2. 列出确定事实与尚可创作的变量；优先锁定主体身份和物体物理结构，再锁定场景拓扑与机位可达性。
3. 区分静态视觉规则与逐镜事件。相机运动依赖空间逻辑；角色动作要有触发、过程和结果；特效应与材料、能量或场景因果相符。
4. 以最终画面倒推时间：每镜只承载一个主要视觉事件，留出观众识别和动作完成的时间。用连续整数秒从0开始编号，总长度不超过30秒。
5. 每镜按连续时间段写视频内容，让背景、主体动作、反应与必要视听变化按发生顺序展开。对白在实际说话处写完整引用与中文双引号，并逐句复写到台词栏。镜头转换通过动作、遮挡、视线或画面因果衔接。
6. 按素材锁定、影片质感、分镜先后生成；最后写1—3句视频梗概。让文字服务于可执行性，而非词藻堆叠。

判断是否拆镜：当一次生成需要同时解决多个独立难题（空间重排、外观变化、多动作链、台词和复杂运镜）时，保留叙事前提下拆分镜头；只有用户明确要求一镜到底或连续空间关系必须保持时优先单镜实现。
