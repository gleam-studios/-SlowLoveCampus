# 重建示范：10秒产品广告（standalone_mode）

纯文本创作示例，未提供任何图像或声音参考，不构造 `@` 文件名。

# 视频梗概
一支深蓝色香氛纸筒置于暖灰色摄影棚中，细小花瓣随风穿过画面，最终停留在清晰完整的包装英雄镜头。克制的真实商业摄影质感。

# 影片质感
影像风格：真实商业产品广告。
摄影偏好：稳定摄影机，以近景与中景组成缓慢运动的连续节奏。
材质与氛围：哑光硬纸纤维、金属烫印与真实花瓣厚薄细节。
光影与色彩：暖灰背景，侧上方柔光，深蓝与金色形成对比。

# 素材锁定
场景：
暖灰摄影棚：无缝背景、浅灰哑光台面，背景没有额外摆设。
角色：
无
道具：
香氛纸筒：深蓝色硬质圆柱纸筒，金色细字，正面图形位置固定；故事中作为主产品展示。
花瓣：来自浅米黄色花朵，薄而柔软，随气流飘动。

# 分镜
镜头01｜0—4秒
视频内容：
0—2秒：暖灰色摄影棚内，香氛纸筒竖立在浅灰桌面中央，背景柔和虚化；细小花瓣从后景被气流吹入，桌边花瓣轻轻颤动。
2—4秒：花瓣绕过纸筒边缘缓慢下落，摄影机沿台面横移，纸筒正面逐渐露出约一半，烫金细字随视角泛起细腻亮光。
拍摄手法：近景机位缓慢横向移动。
光影执行：侧上方柔光随拍摄视角形成细微表面明暗变化。
声音：轻微气流声。
台词：无
结束落点：纸筒正面约半幅露出，花瓣仍在缓慢下落。

镜头02｜4—10秒
视频内容：
4—8秒：切到同一摄影棚的正面近景，摄影机平稳后拉，暖灰背景和桌面逐渐展开；花瓣落在纸筒底部周围，包装正面完整进入画面。
8—10秒：镜头逐渐停稳，产品保持居中，最后一片花瓣触碰桌面后静止，烫金标识清晰。
拍摄手法：正面近景平稳后拉至中景。
光影执行：柔光稳定，金字清晰。
声音：花瓣触碰桌面的轻微沙沙声。
台词：无
结束落点：产品完整居中，花瓣自然散落在周围，镜头停稳。
