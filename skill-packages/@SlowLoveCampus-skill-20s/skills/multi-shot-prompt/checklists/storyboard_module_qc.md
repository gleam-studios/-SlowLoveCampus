# 分镜 QC
- [ ] 镜头从0秒开始按整数秒连续计时；1—9镜，总时长≤30秒
- [ ] 每镜依次含非空的 `视频内容`、`拍摄手法`、`光影执行`、`声音`、`台词`、`结束落点`
- [ ] 视频内容按一个或多个连续时间段写事件，沿用全片绝对秒数并覆盖本镜；段内用连续文字写画面、动作和反应
- [ ] 背景用自然语言描述可见空间及动态环境；场景文件只在素材锁定中绑定
- [ ] 角色和道具按需使用真实 `@` 文件名，各镜位置与持有状态连续
- [ ] 每句对白嵌入实际开口时刻，写成 `@人物A.png说（@人物A音色.mp3）：“台词内容”`
- [ ] 台词栏逐句复写正文对白，说话者、音色、文字、引号、顺序和次数完全一致；无对白写 `台词：无`
- [ ] 人物与音色来自实际素材并正确对应；无人物图用角色名称，无音色文件省略音色括号
- [ ] 语速、口型、表演和伴随动作适合所在时间段；环境音和动作音写入 `声音`
- [ ] 视频内容自然推进至结束落点；镜头间主体状态和空间因果相接
- [ ] 机位、景别和布光与实体环境相容；分镜长度≤5000字
