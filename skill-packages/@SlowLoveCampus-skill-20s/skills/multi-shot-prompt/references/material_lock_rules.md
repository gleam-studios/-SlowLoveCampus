# 素材锁定规则

## 可见结构
`# 素材锁定` 下固定按照 `场景：`、`角色：`、`道具：` 组织。实际给了参考文件时，在对应类别内用原始 `@文件名.格式：` 起行，后接对画面有实际控制意义的描述。其他资产可与其控制的实体绑定，不新增“参考素材”总清单。

## 场景
每个场景参考图说明空间结构、尺度关系、建筑与固定设施的位置、环境属性和镜头间需要继承的方向。例：`@雨夜公交站.png：夜晚的城市公交站，站台有遮雨顶棚，前方是湿润道路，雨水沿顶棚边缘落下。` 场景图仅在这里使用 `@` 绑定。**分镜不出现这一场景文件的 `@` 引用**，而是逐镜以文字描述真实背景、景深、动态天气、光线与空间关系，使背景成为连续场景，而非静态图片贴合。

## 角色
每个角色参考图说明可辨认的面部、年龄呈现、发型、体型、服装与饰物，并写角色的稳定性格、情绪表达和动作/说话风格。叙事中情绪或姿态的具体变化仍在分镜中安排。如果有该人物的实际授权声音样本，将 `音色参考：@人物A音色.mp3（音色特征）` 纳入同一角色条目，保证语音身份可追溯。

## 道具
每个道具/产品参考图说明外形、材料、颜色、结构、相对尺寸、关键识别细节与剧情用途；可变的持有人、开合/运动过程由分镜处理。逐个道具分行。

## 文件和无参考场景
仅引用用户实际提供或当前项目已核实可访问的文件，保留原始名称、空格、大小写和扩展名。无对应图片时，以角色/场景/道具的普通名称作为条目开头；某类实体不存在时写 `无`。音色文件与角色文件分别核实，不得虚构或臆测外观、声音信息。参考视频/音频的权威范围限定到它实际提供的运动、声音或其他特征；多个文件的冲突按属性解决。

本模块锁定跨镜事实，具体摄影方式归影片质感、时间顺序和台词归分镜。总长度≤1000汉字。
