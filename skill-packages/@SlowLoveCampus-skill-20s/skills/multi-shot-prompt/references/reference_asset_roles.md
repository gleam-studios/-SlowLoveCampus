# 参考资产角色与引用

## `@` 文件名的使用位置
提示词引用真实 `@文件名.格式`，必须与输入附件逐字一致（空格、大小写、扩展名均保留）。创作阶段不转换为平台槽位序号，执行层根据实际已上传文件再建立映射。

- **场景图**：只在 `# 素材锁定 > 场景：` 中以 `@场景图.格式：描述` 绑定空间与外观。分镜中的环境背景以文字逐镜描述自然光、雨水、行人、道路和空间透视等动态要素，不出现 `@场景图.格式`，防止整张图被当作静态背景贴图。
- **人物图**：在 `# 素材锁定 > 角色：` 定义外观、性格和表演特征，分镜人物动作/台词可按需持续写 `@人物图.格式`。
- **道具或产品图**：在 `# 素材锁定 > 道具：` 定义外观与功能，相关镜头可持续引用其 `@` 文件名；正常物理动作按分镜文字执行。
- **音色文件**：在对应角色条目中绑定授权声音参考。视频内容在实际开口的时刻使用 `@人物图.png说（@人物音色.mp3）：“台词内容”`，台词栏按同一顺序逐句复写。无声音参考则省略括号；无人物参考图则以角色名称代替人物引用。镜头无对白写 `台词：无`。
- **其他辅助参考**：动作/镜头运动参考视频、起终帧、环境声等，归属其所控制的场景、角色或道具条目，并明确“仅参考什么”。仅在受支持且确有必要的执行层使用额外引用，不将场景参考图放入逐镜正文。

## 多资产权威与执行映射
人物图控制身份与外观，服装图控制服装，产品图控制结构与 Logo，参考视频可仅控制动作节奏、运动轨迹或运镜，不默认改变角色外观；音频只控制经授权的声音特征。冲突以属性级权威解决。

执行时记录 `原始文件名 · 类型 · 角色/场景/道具 · 控制属性 · 所属镜头 · 授权状态 · 目标平台槽位`，只有拿到真实上传映射后才使用对应平台语法。
