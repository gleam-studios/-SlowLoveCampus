# 媒介设备参考

- **手机前置手持**：主体近距广角透视，轻微手臂运动导致边缘形变与取景变化；对焦与曝光响应细微，镜头由拍摄者身体和手部决定。
- **手机后置跟拍**：拍摄者相对主体独立，运镜受步行路径和身体抖动约束；高对比环境可出现短暂自动曝光修正。
- **家用手持相机**：轻微对焦调整、基于机身重量的运动惯性、真实环境音；避免夸张数字变焦。
- **固定监控**：稳定高机位、场景广角、一致压缩、人物在固定空间内进出；无凭空追踪机位。
- **电影摄影**：可控机位、明确景深和曝光质感、光线连续、运镜与场面调度配合；不要用“专业摄影机”一词替代可见视觉语言。

仅选择与实际内容来源相符的 profile；按任务需要写入影片质感，设备数字参数不放进分镜。
