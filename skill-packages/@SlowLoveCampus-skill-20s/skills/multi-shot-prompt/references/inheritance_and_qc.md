# 继承、冲突与审查

## 权威与显示顺序
语义权威按属性划分：实体身份、外观、拓扑以素材锁定为准；摄影风格和影像色彩以影片质感为准；镜头动作/对白/时间以分镜为准；视频梗概是从其余三部分派生的摘要。**可见提示词的排列固定为 `视频梗概 → 影片质感 → 素材锁定 → 分镜`**，不会改变以上属性权威。

## 冲突定位
- 道具外形/数量/服装错误：素材锁定或源文件。
- 光线方向/媒介与摄影方式错误：影片质感或 Style。
- 事件/台词/时间错误：分镜；managed 返回 Master Director。
- 梗概宣称了不存在的事件：仅修改梗概。
- 场景画面呈贴图或静帧感：核对分镜是否直接出现 `@场景参考图`；应只在素材锁定中引用场景，分镜用文字写空间和背景动态。

## 跨镜检查
核对 `@` 引用的附件有效性、每镜视频内容的连续时间段、正文与台词栏的逐句一致性、引号、说话者/音色配对、镜头起止状态、人物/道具持有者、空间方向、背景运动、光源方向、时间与音频发生时点。修改依赖字段后重审下游，不连带改写无关事实。
