# 生成模式路由

选择模式时先确认所接入平台实际能力，以下是概念模式而非保证任何平台均支持。

| 模式 | 必要输入 | 适用问题 |
|---|---|---|
| T2V | 完整四部分提示词 | 无需精确锁定外观、场景能由文本确定 |
| I2V | 起点图、完整提示词 | 以固定起始构图展开动作 |
| R2V | 已声明角色的多参考资产与平台支持情况 | 多资产身份和外观约束 |
| FLF2V | 首尾帧及动作轨迹 | 起点终点必须明确 |
| EXTEND | 已验证的上游成片片段及结束状态 | 正/反向延长已成片 |
| EDIT | 已有视频、授权编辑目标及保留区 | 局部修改、添加、移除或替换 |

所有模式只改变执行层资产绑定，不产生额外新提示词。对平台不支持的输入组合直接阻断或返回改由上游选择，不假装支持。对于 EXTEND，不能把未经实际审片通过的模拟 take 作为正式起点。
