# 模拟测试：两个人物、三个道具、一个场景（standalone_mode）

本案例的所有 `@` 文件名都是**测试用假设附件**，不代表资料库存在这些文件；仅用于验证格式及跨镜连续性。假设另有两段授权角色音色样本。

# 视频梗概
20秒都市雨夜告别短片。公交站下，男子把纸质车票和一把红色雨伞交给即将离开的女子，女子撑伞拖着行李箱走入雨夜，男子留在站台目送。真实克制的情感电影质感。

# 影片质感
影像风格：写实都市情感电影，生活化表演。
摄影偏好：稳定摄影机，依次使用站台中远景、交接近景、表情特写和送别中景；摄影运动克制。
材质与氛围：雨滴、湿衣、纸张、伞布和地面反射真实，情绪安静。
光影与色彩：冷蓝雨夜环境与站台暖黄照明，柔和自然曝光。

# 素材锁定
场景：

角色：
@人物A.png：二十多岁的成年女子，黑色齐肩发、深灰色风衣、平底鞋；独立内敛，习惯将情绪收在眼神与短暂点头中。音色参考：@人物A音色.mp3，轻柔偏低、语速较慢。
