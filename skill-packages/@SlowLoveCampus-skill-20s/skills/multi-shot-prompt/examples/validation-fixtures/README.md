# 格式校验用例
本目录记录模拟文本检查，不代表实际生成结果。

`scripts/validate_skill_contract.py` 自动检查完整提示词的标题顺序、影片质感四字段、素材分类、分镜字段、镜头时间与镜内时间段、素材引用、台词格式及正文/台词栏逐句一致性。脚本包含正向示例和错误变体测试，每个错误变体须与原文不同并触发对应类别的错误。
正文与台词栏的说话者、音色、文字、引号、顺序、次数需要同时匹配；无对白时使用 `台词：无`。镜内时间段可以是单段、多段或小数边界，均需按绝对秒数完整覆盖所属镜头。

## 人工与执行层审查
执行模式、审批内容与哈希真伪、肖像/音色授权、自拍机位物理一致性、叙事和动作合理性、口型及语速、实际附件可访问性、成片证据与连续性需要另行核实。自动格式校验的通过不替代这些检查。
