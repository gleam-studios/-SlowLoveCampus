# 成片证据与续写状态

正式 take 必须包含 `take_id`、所属 `shot_id`/分镜版本、媒体引用、生成服务与模式、生成参数指纹、观察时间、审查人/来源、`evidence_mode: observed`、`accepted: true`、`test_only: false`，并记录可观察的实际末帧/末状态。

仅满足以上条件的已审片段可进入生产连续性链。`simulated`、未审、被拒、无媒体证据、只凭提示词推断的状态均属于非生产证据，不能作为续写起点。下一段继承实际画面中观测到的人物衣着、位置、道具朝向、光线状态及摄影机位置，而非只继承原定愿望。

审查记录中的评价与修复建议是证据层，不自动覆盖原始素材锁定或已批准风格。
