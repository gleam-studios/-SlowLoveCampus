# 真人感日常自拍模式

## 进入条件
明确 `content_mode: realistic_daily_selfie_mode`，且有一张可用的起点截图。人物应为明确成年的虚拟角色或已满足肖像授权条件的真人。默认通过 I2V 延展这张起点截图，约10秒一镜连续发生。

## 摄影机归属
只选一种 `capture_mode`：
- `front_camera_selfie`：角色本人持手机，前置镜头拍摄，屏幕不应作为外部画面显示；手的占用和镜头位置同步，画幅出现符合手臂长度的近距透视。
- `mirror_selfie`：镜面反射显示持机者和手机；成片机位是手机，镜面位置、人物目光和反射方向需连续。
- `third_party_capture`：摄影者在人物之外，人物双手按画面动作自由使用；相机与人物距离、视线、步态有合理解释。
起点截图与模式冲突返回 `E_CAPTURE_SOURCE_CONFLICT`。

## 动作节奏
起始0秒画面即具有可辨识的单一视觉钩子；一个主运动，至多两个辅助变化。写明主运动起止、自然微动作、手持微抖、广角透视、自动曝光/对焦响应和结束落点。服装、场景、面部及身体比例保持连续。逐镜始终保留 `台词：` 字段，无人说话写 `台词：无`；有对白时在视频内容对应时间段写 `@人物图.png说（@人物音色.mp3）：“台词内容”`，并在台词栏逐句复写；仅使用实际角色图和授权音色文件。环境声归 `声音：`。

## 核验
确认机位物理位置、手机可见性、视线、手部占用和连续性一致；模拟环境必须标为模拟，不伪称真实记录。参考 `checklists/realistic_daily_selfie_qc.md`。
