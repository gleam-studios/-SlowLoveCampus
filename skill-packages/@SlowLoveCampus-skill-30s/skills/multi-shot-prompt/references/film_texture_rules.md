# 影片质感规则

从已锁定素材出发制定统一的摄影/成像方式，避免重复主体身份。

## 必需信息
- 风格类型：纪实、商业广告、动画、模型拍摄等可见影像语法。
- 摄影偏好：机位归属、构图倾向、景深与运动惯性；独立于本片段的具体动作。
- 材质呈现：皮肤/纸张/玻璃/金属等光泽、粗糙度、细节层次、颗粒与动态模糊。
- 氛围：明暗关系、环境可见性、真实摄影质感或受控艺术表现。
- 光影与色彩：主光方向、软硬、亮暗层级、色温及色彩关系。

输出格式必须保留四个独立字段及固定顺序：`影像风格：`、`摄影偏好：`、`材质与氛围：`、`光影与色彩：`，每一项都有可执行的正向画面描述。整体段落即使涉及全部要点，也不等同于四字段格式。

不在此处规定单镜时间、人物动作、对白、镜头位置变化或虚构物体。启用自拍模式时按输入写一致的 `摄影机身份：[capture_mode]`，不另造拍摄来源。输出1000汉字以内。
