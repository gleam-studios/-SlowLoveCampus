# 素材锁定 QC
- [ ] 固定且仅有三个顶层分组：`场景：`、`角色：`、`道具：`，顺序一致
- [ ] 有场景图时用 `@场景文件.扩展名：` 定义场景结构与环境，分镜正文不重复引用这一场景图
- [ ] 人物图逐一写出外观、服装、稳定性格与表演特征
- [ ] 道具图逐一写出外观、构造、材质、尺寸关系和实际用途
- [ ] 有授权音色素材时，按角色配对 `音色参考：@角色音色.扩展名`
- [ ] 所有 `@文件名.格式` 对应真实已提供/可访问文件，原样保留空格大小写与扩展名
- [ ] 无参考资产使用普通名称；该类没有实体时写 `无`
- [ ] 场景拓扑、角色身份、产品Logo等跨镜事实无冲突
- [ ] 不混写单镜时间、运镜或对话；长度≤1000字
